# F12_supercritical.mp4

## Summary

Clip on a key safety distinction: separate SELF-IMPROVEMENT from SELF-GOVERNANCE. A loop should be able to improve its operation, but it should NOT be able to change what it does. That separation is what keeps it from going supercritical.
