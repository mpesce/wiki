# F15_specification-over-code.mp4

## Summary

Clip. Software is 'at the cliff face' because it has been using the tools long enough: people are no longer worrying about the CODE that AI generates — what they sweat over is the SPECIFICATION used to generate that code. The spec must be clear and explainable to both machine and human readers, because the human readers are the judges and verifiers. Ratifying a specification means defining what you're doing and getting it right.
