# F2b_watershed-in-context.mp4

## Summary

Clip. The 'watershed' in fuller context: the point at which an agent completes a task before it falls over, giving high confidence it will finish. Crossing it means the human moves from IN the loop to ON the loop, checking in occasionally, which changes the cost calculus of agentic AI. Before the watershed, all of human history, cognitive labor had one source: us.
