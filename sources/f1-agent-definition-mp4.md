# F1_agent-definition.mp4

## Summary

Clip from Mark's 'AI in Practice' series. Defines an agent: basically an AI plus three things — (1) some memory, a scratch pad so it can track what it is doing; (2) tools, so it can read/write a file, send an email, read a spreadsheet; and (3) goal logic, 'the part that is like the Terminator' — the part that keeps going on the job until it gets it done. Slap those three things onto an AI and you have an agent. He reflects back to 2023 when the first agents appeared.
