# D9_easy-to-be-safe.mp4

## Summary

Clip on safe agent deployment. Keep agents relatively well isolated, with access to only the data they need to solve the problem. Containers are very well understood: it's really easy to spin up an agent in a container with just the dataset it needs, let it do its work, and then delete the whole thing. 'It's easy to be safe,' but we haven't had to work that way with any of our other tools.
