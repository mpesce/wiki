# Python

## TL;DR

The programming language Pesce adopted in 2010 (and the language of his Plexus network) — plus one 2014 source that is the animal, a three-meter carpet python named Monty.

## Overview

Python (the programming language) enters the corpus through the **2010 keynote at the first Python convention** (How Not To Be Seen). Pesce traces his four-decade language history "from RPG and assembly to C++ and JavaScript", and explains that he **recently adopted Python**, "finding its power and community ethos compelling", which led him to install it on all his devices. This shift coincided with his frustration with centralized social networks (particularly Facebook, which he left as a "digital refugee"). To address this he introduces **Plexus**, "a second-generation, decentralized social network architecture **written entirely in Python**" — personal, portable, private, open source, grassroots; the talk's core is a live demonstration (sharing a URL across Twitter, Posterous, Tumblr and SMTP using separate Python modules), and he highlights "Python's culture of sharing as the ideal foundation for this new infrastructure" ([[sources/hownottobeseen-mp4]]). The second source is a **false positive**: the 2014 *The Project* (Channel 10) broadcast covers "a Brisbane family's encounter with a three-meter **carpet python** named Monty, which had entered their bedroom" — the animal, not the language ([[sources/0000000019b5b787-mpg]]). The corpus's Python is therefore the language of the 2010 talk (the adopted language, the Plexus implementation language, the culture of sharing) with the 2014 animal tag held as a distinct referent.
