# JavaScript

## TL;DR

The language of the web in the corpus — in Pesce's career résumé (2010) and as the 2026 clip's subject: the 10 MB of unused JavaScript that agents will optimize.

## Overview

JavaScript appears in the corpus in two distinct registers. In the **2010 keynote at the first Python convention** (How Not To Be Seen), JavaScript is part of Pesce's four-decade language history — "tracing his path from RPG and assembly to C++ and JavaScript" — the language of the web he worked in before adopting Python ([[sources/hownottobeseen-mp4]]). In the **2026 A-series clips**, JavaScript is the subject of its own argument: "a big deal" — "software has never been well optimized because optimization was slow and expensive — it required people. That's why your webpage loads 10 MB of JavaScript: a lot of it is unused and unoptimized because it's more expensive to optimize than to ship. Now agents will run in the background optimizing all our software, so everything we use is about to get a lot more optimized" ([[sources/a12-10mb-javascript-mp4]]). The corpus's JavaScript is therefore both the web's lingua franca in the 2010 talk and the standing example of the unoptimized-software problem that the 2026 agentic era will solve.
